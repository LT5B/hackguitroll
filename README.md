## How to open Terminal/Termux/Command Prompt?
- Open Terminal on MacOS:
+ Step 1: Click Cmd + Space
+ Step 2: Write "Terminal"
+ Step 3: Click Enter
+ Step 4: Run your command

- Open Terminal on Linux:
+ Step 1: Click Ctrl + Alt + T
+ Step 2: Run your command

- Open Termux on Android:
+ Step 1: Go to Play Store
+ Step 2: Click the search button
+ Step 3: Search Termux
+ Step 4: Install Termux
+ Step 5: Go to Termux
+ Step 6: Run your command

- Open Command Prompt on Windows:
+ Step 1: Click Win + R
+ Step 2: Write "cmd"
+ Step 3: Run your command
